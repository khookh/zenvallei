# Security policy

Greenwave is a static public map with no accounts, backend, analytics or user-submitted data.

Please report a suspected vulnerability privately to [stefanodonne@gmail.com](mailto:stefanodonne@gmail.com). Include the affected URL, a concise reproduction and the potential impact. Do not include credentials or personal data, and do not open a public GitHub issue for an unresolved security problem.

Reports about incorrect map data or accessibility can use the same address. Upstream data corrections may need to be referred to the official data producer.
